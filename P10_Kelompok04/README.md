# PRAKTIKUM 10 — KELOMPOK 04
## Kecerdasan Bisnis | Sample Superstore

Repositori ini berisi paket pengumpulan Praktikum 10 Kelompok 04. Isi paket menggabungkan laporan utama, laporan teknis dan validasi Wahyu, dokumentasi data preparation Vhirginia, file Power BI, workbook model, dokumentasi DAX, dan bukti screenshot.

## Struktur folder

| Folder | Isi |
|---|---|
| `01_PBIX/` | File Power BI kelompok. File ini memuat halaman P10 dan halaman P11 tambahan dalam satu PBIX sesuai keputusan kelompok. |
| `02_LAPORAN/` | Laporan utama Wira, laporan teknis Wahyu, dan laporan analisis/validasi Wahyu dalam DOCX dan PDF. |
| `03_DATA_PREPARATION/` | Cleaning Log dan Data Dictionary dari proses persiapan data. |
| `04_MODEL_DAN_DAX/` | Workbook model, DAX KPI dan key checks, dokumentasi DAX, spesifikasi relationship, serta bukti rumus dan validasi DAX. |
| `05_BUKTI_P10/` | Screenshot Power Query, Data Dictionary, profiling, Model View, relationship, key checks, rekonsiliasi, dan diagram model. |

## Ruang lingkup laporan P10

Praktikum 10 mendokumentasikan:
1. Pemeriksaan struktur dan kualitas dataset Sample Superstore.
2. Persiapan data menggunakan Power Query.
3. Penetapan grain dan rancangan model dimensional.
4. Dokumentasi delapan relationship target.
5. Penyusunan delapan KPI inti dan indikator tambahan Return Rate.
6. Pemeriksaan key dan rekonsiliasi Region East–Januari 2024.

Dataset Sample Superstore memiliki tiga tabel sumber utama, yaitu Orders, Returns, dan People. Model analitis yang dibahas dalam laporan menggunakan empat dimension dan tiga fact. Definisi, hasil, dan batas interpretasi indikator dijelaskan di dalam laporan utama dan laporan validasi.

## Catatan file Power BI

File PBIX dalam folder `01_PBIX` dipertahankan sebagai satu file kelompok yang memuat halaman Praktikum 10 serta halaman P11 tambahan. Halaman P11 tidak dipisahkan, sesuai keputusan kelompok. Fokus penilaian dan pembahasan pada paket ini tetap Praktikum 10.

## Cara mengunggah ke GitHub

1. Ekstrak ZIP ini.
2. Unggah seluruh isi folder `P10_Kelompok04_FINAL_SIAP_GITHUB` ke direktori repository yang ditentukan dosen.
3. Pastikan `README.md` berada di root repository agar tampil otomatis pada halaman GitHub.
4. Pertahankan nama folder dan nama berkas agar tautan bukti di README serta manifest tetap konsisten.
5. `MANIFEST_SHA256.csv` dapat digunakan untuk memeriksa integritas berkas setelah diunduh.
